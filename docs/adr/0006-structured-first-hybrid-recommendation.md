# ADR-0006：结构化优先的混合推荐，Phase 1 开展受控 LLM 实验

- Status: Proposed
- Date: 2026-08-27

## Context

历史数据少且非结构化，工程安全要求高。LLM 适合提取和草拟，不适合无约束地做正式选型。

## Decision

推荐顺序为归一化、硬约束、相似案例、工艺组合、确定性校核、设备筛选、多目标评分和解释。Phase 1 即加入 LLM 实验，用于文档提取、字段映射、翻译草稿、说明草稿和候选建议。LLM 输出必须标记模型与 prompt 版本，进入暂存/人工确认或确定性规则校核，不能直接发布工程事实、正式流程或最终设备选型。

## Consequences

MVP 在少数据情况下可控、可解释，同时能尽早评估 LLM 的实际价值、成本和错误类型。需要工艺专家投入规则、模板和金标准，不会获得“上传全部 PDF 就自动学习”的虚假快捷方式。
