# ADR-0009：初步客户文件采用权限型审核，不绑定组织职级

- Status: Proposed
- Date: 2026-08-27

## Context

初步 PDF/DOCX 需要在客户现场交付，不能等待工艺工程师，但仍必须有人检查实际打印内容。审核人可能是销售团队负责人、主管或其他被指定人员，因此不能把权限硬编码为某个职级。

## Decision

- 从销售方案修订冻结指定语言与格式的 `CustomerHandout`，先生成不可变审核版本。
- 只有持有逻辑权限 `customer.handout.review` 的主体可以批准或退回。
- 审核针对具体 handout manifest、语言、文件 checksum 和免责声明版本；内容改变后必须重新审核。
- 审核通过后状态变为 `APPROVED_FOR_DELIVERY`，才允许现场打印、下载或交付客户。
- 不要求工艺工程师参与；文件继续显示“未经最终工艺审核”的醒目标识。
- 默认制作者不能审核自己生成的文件；是否允许紧急自审保留为可配置开放项。

## Consequences

审核责任可通过 BMS 权限灵活分配，不依赖组织架构名称。平台需要新增 handout 审核状态、审核记录、权限映射、待办页面和审计事件。

## Rejected Alternatives

- 固定为“销售团队负责人”：职级与实际授权可能不一致。
- 由工艺工程师审核：不能满足现场即时交付目标。
- 生成后无需审核直接打印：无法证明具体客户文件有人检查过。
